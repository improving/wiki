# CodeRush

CodeRush is a Visual Studio productivity add-in that this corpus compares head-to-head with ReSharper and uses to illustrate template-driven, low-friction code generation.

## Overview

Across a six-month comparison, CodeRush won on context-aware mnemonic templates and unified account-based licensing, while ReSharper won on refactoring navigation and file generation from the solution explorer. The author ultimately recommended ReSharper because its single key binding set fit his habits, but concluded both beat using neither.

The companion post treats templates as the point of the tooling: a `Person` class was generated in 19 seconds via keystrokes, and templates also scaffold TDD tests with assertions pre-filled. The stated goal is reducing friction between intent and implementation, not typing speed, and targeted generation cuts typographical errors.

## Key Claims

- CodeRush wins on context-aware mnemonic templates and unified account-based licensing
- ReSharper wins on refactoring navigation and file generation from the solution explorer
- A `Person` class was generated in 19 seconds via keystrokes
- Templates scaffold TDD tests with assertions pre-filled
- The goal is reducing friction between intent and implementation, not typing speed
