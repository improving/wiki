# Microsoft Syntex

Microsoft Syntex is Microsoft's content AI for SharePoint, appearing in this corpus through two capabilities: eSignature for capturing signatures without leaving Microsoft 365, and metadata extraction inside a contract management solution.

## Key Claims

- Microsoft announced Syntex eSignature at Microsoft Build 2023, letting users send signature requests while content stays in Microsoft 365; it entered public preview in July 2023.
- Common e-signature cases include sign-off policies, compliance training proof, purchase orders, and other formal policies.
- Syntex eSignature will not remove the need for DocuSign or Adobe Sign for external parties, but is a good option for internal signatures.
- In a contract lifecycle management build, Syntex performed metadata extraction from documents, alongside SharePoint for storage and [Power Automate](/entities/power-automate.md) for workflows.
- Adoption advice: refresh information architecture and add metadata such as signer, signed date, and document type so signed documents stay findable.
