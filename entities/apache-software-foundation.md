# Apache Software Foundation

The Apache Software Foundation (ASF) is the non-profit foundation stewarding many of the projects this corpus builds on — Kafka, Flink, Spark, TinkerPop, and Camel among them. It appears less as a company than as the governance and release authority behind the open-source infrastructure that streaming, data processing, and graph work depend on.

## Governance

- Each project is governed by a Project Management Committee (PMC) that holds sole authority to vote on formal releases.
- PMCs also vote in new committers and PMC members, making them the gatekeepers of project membership.
- Improving consultant Yang Xia became the firm's first Apache PMC member, recognized for work on Apache TinkerPop.

## Projects in This Corpus

- Apache Flink is a unified stream and batch processing framework and a top-five Apache project; it powers stream processing at Uber, Netflix, LinkedIn, ING, Goldman Sachs, and Comcast.
- Apache TinkerPop is a graph computing framework for graph databases (OLTP) and graph analytics (OLAP), with the Gremlin traversal language analogous to SQL.
- Apache Camel is an integration framework; an MQTT5-to-Kafka at-least-once delivery fix was contributed upstream as CAMEL-21589.
- Apache Kafka is the event streaming platform at the center of the corpus's real-time architectures.
