# Cloud Security Alliance

The Cloud Security Alliance (CSA) appears in this corpus as the standards body whose agent-maturity levels and evidence expectations frame how enterprises govern task agents and third-party vendors.

## Overview

One post notes that most deployed agents sit at CSA level 100–200 with informal governance, while Gartner projects 40 percent of enterprise apps will embed task agents by the end of 2026. The remedy is a hybrid centralized-federated model in which review rigor scales with a skill's risk and a cross-functional board with real authority owns skill approval.

A related argument applies the same discipline to vendors: an allow-list approved requests against stale evidence over 30 percent of the time, so approval should be re-earned at request time against pen-test, SOC 2, scan, and uptime thresholds.

## Key Claims

- Most deployed agents sit at Cloud Security Alliance level 100–200 with informal governance
- Gartner projects 40 percent of enterprise apps will embed task agents by end of 2026
- Centralize everything or federate everything both fail; hybrid is the answer
- An allow-list approved requests against stale evidence over 30 percent of the time
- A vendor approved yesterday is denied today once its pen test expires
