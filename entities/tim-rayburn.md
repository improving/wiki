# Tim Rayburn

An Improving technologist and writer whose AI-era posts center on [context engineering](/concepts/context-engineering.md) — the discipline of maintaining durable, shared project context so AI-assisted work stays reliable at scale. He also writes accessible explainers on distributed-systems design.

## Topics and Work

- Argues vibe coding cracks in enterprise systems not because AI can't write code but because teams ignore the [context window](/concepts/context-window.md) and how LLMs fail, spending more time correcting the AI than benefiting from it.
- Proposes "living context": durable artifacts describing not just what to build but how, stored as a shared source of truth that the AI reads, plans from, implements against, tests, and writes learnings back to.
- Notes that shared context scales for teams — one developer's update benefits every other developer and every assistant — and that acceleration without direction only gets you lost faster.
- Explains distributed systems through the choice between synchronous communication ("phone calls") and asynchronous messaging ("postal service"), arguing async is the more powerful default and robust systems blend both.
