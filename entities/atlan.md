# Atlan

Atlan appears in this corpus as a [data catalog](/concepts/data-catalog.md) product representative of the shift from passive, manually curated metadata to [active metadata](/concepts/active-metadata.md) captured as a byproduct of system operation. It anchors the argument that a catalog is a discovery surface — for people and increasingly for models — rather than a static inventory.

## Overview

The same discovery problem repeats at the [skill registry](/concepts/skill-registry.md) layer: a `SKILL.md` is structurally a knowledge object someone must find at need, and [Skill Discovery](/concepts/skill-discovery.md) faces the retrieval failures catalogs already fought. The corpus argues a [metadata knowledge graph](/concepts/metadata-knowledge-graph.md) can model prompt-model-data relationships that flat catalog entries cannot.

## Key Claims

- Passive catalogs go stale because curation is underfunded manual work; active metadata is captured automatically.
- Gartner retired its Metadata Management Magic Quadrant for Active Metadata Management in 2021, reframing governance as enablement.
- A folder of skills is a shared drive, not a registry; governance needs gates, scope, review, and version pinning.
- SkillsBench scored 47,150 public skills at 6.2 out of 12 average quality; curated, reviewed skills raised pass rates by 16.2 points.
- Retrieval over catalog metadata differs from retrieval over prompt content, so one search strategy will not serve both.
