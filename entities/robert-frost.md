# Robert Frost

Robert Frost is the American poet whose "Mending Wall" — and its line "good fences make good neighbors" — provides the framing for Daniel Scheufler's Improving essay on API design. The poem's ambivalence about walls mirrors the essay's argument that an API boundary shapes human behavior, not just code.

## Use in This Corpus

- An API — a class interface, a library facade, or a vendor's REST service — is a fence with approved entry points that marks what is "mine" and what is not.
- That boundary is useful but limiting: discovering a bug just past the entry point tempts developers to leave it for the owning team.
- The essay reads this as Conway's Law at work, since organizations tend to build systems that mirror their own communication structure.
- Amazon's "Team APIs" memo turned an API question into a "how we do business" question and, apocryphally, laid the groundwork for AWS.
- The design question becomes whether the architecture encourages the behaviors the company needs — mutual support or strong separation of duties.
