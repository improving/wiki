# Confluent

Confluent is the commercial steward of Apache Kafka and the vendor most often named in this corpus's real-time data streaming work. It sells managed Kafka (Confluent Cloud) plus stream processing, schema management, lineage, and governance tooling, and appears both as the delivery platform for customer cases and as a partner to Improving, which holds Confluent Elite Systems Integrator credentials.

## Role in the Corpus

- Improving describes $40M+ in event streaming solutions since 2013 and co-authors Confluent-facing thought leadership.
- A Fortune 100 client in a regulated industry used on-prem Confluent Platform plus Confluent Cloud for zero-downtime event capture across its distribution network.
- Medtronic streamed sensors, MES systems, and MQTT brokers into Kafka, scaling across 350 sites with Confluent Cloud.

## Key Products

- Confluent Cloud: managed, cloud-native Kafka, paired with a serverless Apache Flink service that reached general availability across AWS, Azure, and Google Cloud with a 99.99% uptime SLA.
- Schema Registry enforces data contracts and discoverability; Stream Lineage and Data Portal provide observability and data discovery.
- Cluster Linking replicates events from on-prem clusters to the cloud for centralized availability and recovery.
- TableFlow converts Kafka streams into Delta Lake tables for unified operational and analytical pipelines.
- The Q4'25 release added Streaming Agents — defined in a few lines of code on managed Flink and Kafka — with agent observability and a Real-Time Context Engine served over MCP.
