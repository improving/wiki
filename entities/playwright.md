# Playwright

Playwright is the newest of the three browser test-automation tools compared in this corpus, and the one pitched as the modern cross-browser default. It also surfaces as Microsoft's Playwright MCP, a recommended testing server for AI coding agents.

## Capabilities

- Supports Chromium, Firefox, and WebKit, automates iframes and shadow DOM, runs tests in parallel natively, and includes native API testing.
- Positioned against the older tools: Selenium for breadth and maturity, Cypress for developer ergonomics, Playwright for a unified modern API.
- Caveats named in the comparison are a smaller community than Selenium, enterprise hesitancy toward a newer tool, and compatibility churn from frequent updates.
- Microsoft ships a Playwright MCP server, listed among the recommended testing servers for connecting AI assistants to real systems.
