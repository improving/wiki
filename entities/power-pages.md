# Power Pages

Power Pages is an extension of [Power Apps](/entities/power-apps.md) for building externally visible websites and portals, sitting between simple site builders and fully custom-coded solutions. Support in this corpus is a single product overview, so this page is deliberately short.

## Key Claims

- It combines a drag-and-drop UI designer with direct HTML, CSS, and JavaScript editing, and supports custom domains with SSL.
- It integrates with SharePoint, [Power BI](/entities/power-bi.md), and Dynamics 365, and supports authentication through Azure AD, Gmail, and Facebook.
- CDNs improve performance and progressive web app support enables a seamless mobile experience.
- [Microsoft Copilot](/entities/microsoft-copilot.md) provides a starting point and handles straightforward tasks; keyword search and auto summaries are additional AI features.
- Governance uses web roles plus table and page permissions; case studies include Intralux's technician portal for work orders and inspection reports, and Akuma extending customer data to distributors.
