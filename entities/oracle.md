# Oracle

Oracle is an enterprise software and cloud vendor that appears in this corpus in two roles: as an example of matching workloads to a second cloud provider, and as the on-premises database left behind in a legacy modernization case. It stands for the incumbent enterprise stack that modernization and multi-cloud strategies are often built around.

## In Multi-Cloud and Hybrid Strategy

- Oracle Cloud is cited as the kind of specialist provider a multi-cloud strategy might pair with AWS — for example running web applications on AWS while keeping ERP on Oracle Cloud.
- The rationale is cost optimization and vendor lock-in avoidance, at the price of redundant resources, egress premiums, and the need for provider-specific expertise.

## In Legacy Modernization

- In Improving's buyer's guide, Berkshire Hathaway Energy ran a legacy Java Swing application on on-premises Oracle.
- Improving moved that application to cloud-native React and Java [microservices](/concepts/microservices.md) on Azure, with [Apache Kafka](/entities/apache-kafka.md) as the messaging backbone — delivering 2 to 3 features per sprint and about 5 minutes to spin up a replacement environment.
