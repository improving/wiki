# Sarvani Yallapragada

Sarvani Yallapragada is an [Improving](/entities/improving.md) writer specializing in LLM and RAG evaluation, the Model Context Protocol, AI security, and data reliability. Her posts are practitioner-oriented, combining frameworks, tool comparisons, and worked examples.

## Work

- Authored "How to Approach LLM Evaluation for AI-Native Applications," on continuous quality measurement and tooling.
- Wrote "Evaluating RAG Systems with DeepEval Metrics," a hands-on walkthrough of the RAG Triad as pass/fail gates.
- Authored "When MCP Is Not The Right Choice," on the hidden operational and security costs of the Model Context Protocol.
- Wrote "Best MCP Servers for Software Developers and Engineers," a curated, hardened tool list.
- Authored "AI Code Review Isn't Code Review Yet," on the gap between pattern matching and architectural judgment.
- Wrote the OWASP Top 10 for LLM Applications guide and a "Data Debt" essay.
