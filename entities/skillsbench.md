# SkillsBench

SkillsBench is a benchmark that evaluates public agent skills (SKILL.md packages) for quality. In this corpus it supplies the hard numbers behind the argument that skill libraries repeat the discovery, duplication, and curation failures of document stores and shared drives.

## Overview

One post treats a SKILL.md as structurally just another knowledge object someone must find at need, with progressive disclosure loading name and description first and body and scripts later. SkillsBench scored 47,150 public skills at an average 6.2 out of 12. The companion post reports that curated, reviewed skills raised agent pass rates by 16.2 points — 51.9 in healthcare — while an unmanaged skills marketplace accumulates duplicates and insecure packages.

## Key Claims

- SkillsBench scored 47,150 public skills at 6.2 out of 12 average quality
- Curated, reviewed skills raised pass rates 16.2 points, and 51.9 points in healthcare
- A SKILL.md is structurally a knowledge object someone must find at need
- Progressive disclosure loads name and description first, body and scripts later
- Unmanaged skill libraries accumulate duplicates and unreviewed, insecure skills
