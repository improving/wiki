# Microsoft Planner

Microsoft's cloud-native task and project management tool, the current endpoint of a line that runs from the 1984 desktop Microsoft Project through Project Server and Project Online. This corpus treats the rebuilt Planner as an example of [modern ways of working](/concepts/modern-ways-of-working.md): simple enough for small teams, scalable enough for large organizations, and embedded in the [Microsoft](/entities/microsoft.md) 365 surface where teams already work.

## Evolution

- Microsoft Project (1984) was powerful but weak on collaboration; Project Server added a centralized database at the cost of significant administration.
- Project Online (2011) moved project management to the cloud and integrated with SharePoint but eventually showed its age.
- The new Planner is cloud-native and built on the [Power Platform](/entities/power-platform.md), following Microsoft's shift to platform-based delivery.

## Capabilities

- Integrates with [Microsoft Teams](/entities/microsoft-teams.md), where plans live alongside team conversations.
- Adds [Microsoft Copilot](/entities/microsoft-copilot.md) for plan creation and generating status reports.
- Offers task-board, Gantt, and timeline views, and connects to [Power BI](/entities/power-bi.md) for advanced reporting.
- Basic features are included with most Microsoft 365 licenses; premium capabilities are priced separately.
