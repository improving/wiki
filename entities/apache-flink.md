# Apache Flink

Apache Flink is a stream-processing engine for stateful computation over events, presented in this corpus as the de facto standard and increasingly as the runtime for event-driven AI agents. It is paired throughout with Apache Kafka and delivered managed through Confluent.

## Where It Appears

- A unified stream and batch processing framework and a top-five Apache project; it powers stream processing at Uber, Netflix, LinkedIn, ING, Goldman Sachs, and Comcast.
- Confluent reached general availability for a cloud-native, serverless Flink service across AWS, Azure, and Google Cloud, with a 99.99% uptime SLA, running beside its managed Kafka.
- Combined Kafka + Flink enables filtering, joining, and enriching streams with integrated monitoring, security, and governance.
- Confluent's Streaming Agents are embedded in Flink streams using familiar Flink APIs, with native support for model inference, tool calling over MCP, embeddings for RAG, and ML functions.
- Flink drew the strongest attendee interest on Improving's 2025 Data Streaming World Tour, prompting hands-on workshops after each stop.
- Named among the open-source ingestion and processing options alongside Kafka, Spark, and NiFi in cloud data management.
