# H.264

H.264 (AVC) is a video compression standard widely used in live streaming and video conferencing. In this corpus it is the compatibility baseline that makes RTP passthrough practical: because both RTSP cameras and WebRTC endpoints speak H.264, a relay can forward encoded packets instead of transcoding them.

## Key Claims

- H.264 baseline and main profiles maximize WebRTC decode compatibility across browsers.
- RTSP and WebRTC both carry media over RTP, so an H.264 stream can often be repackaged rather than re-encoded.
- Passthrough still depends on codec profile compatibility with the browser's decoder, so profile choice matters.
- Endpoint capability should be detected at connection time via isConfigSupported rather than assumed from a build flag.
- Eliminating transcoding beats speeding it up for CPU scaling.
