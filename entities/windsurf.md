# Windsurf

Windsurf is an agentic coding IDE, formerly Codeium, that now sits inside [Cognition](/entities/cognition.md) and is branded Devin Desktop. It recurs across this corpus as the practical demo environment where Improving consultants show AI-assisted development in the open.

## Role in the Corpus

- In the AI maturity walkthrough, Windsurf (with Code Explorer) is the default "Stage 2" configuration — no MCPs, rules, workflows, or skills — producing call-and-response work whose context never travels between sessions.
- Moving past that ceiling means persisting plans into the repo, writing the process down as reusable workflows, and promoting workflows into AI-triggered skills, shifting the developer from doer to director to system designer.
- Claudio Lassala uses Windsurf for plan mode and backlog generation, and for a 3,000-test migration where [Model Context Protocol](/entities/model-context-protocol.md)'s Context7 server supplied current library information.
- It is cited as an AI tool for accessibility remediation work on a large legacy project.

## Adoption and Positioning

- Improving's February 2026 partnership with Cognition deploys Windsurf as the easy on-ramp for Stages 1–3 of the eight-stage [AI maturity model](/concepts/ai-maturity-model.md), with [Devin](/entities/devin.md) providing autonomy at higher stages.
- Windsurf appears among the developer tools (with Cursor and [GitHub Copilot](/entities/github-copilot.md)) in the agent-era tool landscape.
- It was the subject of an "AI-enabled IDE" episode in Improving's "Ship Faster With AI" video series.
