# Devlin Liles

Devlin Liles is an Improving consultant and writer whose posts on delivery maturity, the scaffolding around AI, and shared vocabulary supply much of this corpus's systems-thinking spine.

## Key Claims

- A team's thinking is bounded by its shared vocabulary, so naming recurring concepts is high-leverage work.
- Effective throughput is gated by review capacity, not generation speed, so permission mode makes humans a linear constraint.
- The model alone yields 70% solutions; scaffolding — context, testing, review, and CI/CD — converts that to 95%.
- Maturity is how much work you can responsibly hand off, not how good your tools are.
- Each orchestration layer costs roughly seven times the effort of the one below it.
- Skill documents can be optimized like weights, but instructions decay over long trajectories.
