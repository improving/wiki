# GitHub

GitHub is the dominant code hosting and collaboration platform. In this corpus it appears both as a venue for deliberate learning and as part of the broader story about how AI tooling and usage-based pricing reshape software work.

## Overview

One post describes a .NET developer beginning a language apprenticeship in Ruby, pairing Ruby Koans with a console game project. The goal is learning Ruby properly rather than writing C# in Ruby — a craft-oriented stance toward a host language, with a public repository as the artifact.

The other post argues that flat-rate AI pricing was customer acquisition, and that every seat product is a meter in disguise. Spend follows new model releases with zero lag and no price check, and a tokenizer change once effectively raised prices up to 35% with no announcement. Cost per unit of finished work is the only metric the vendor cannot quietly move.

## Key Claims

- Apprenticeship pairs Ruby Koans with a console game project to learn a language properly.
- The goal is learning Ruby as it is, not writing C# in Ruby.
- Every seat-based product is a meter in disguise.
- A tokenizer change effectively raised prices up to 35% with no announcement.
- Cost per unit of finished work is the metric the vendor cannot quietly move.
