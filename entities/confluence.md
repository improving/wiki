# Confluence

Confluence is the Atlassian knowledge base that this corpus uses as the substrate for two arguments: that institutional learning needs operational design, and that a wiki needs a way to measure which sources are believable.

## Overview

On learning, the ImprovingU account holds that values without structure produce uneven, non-compounding learning. It used semester-based global courses plus quarterly local cohorts with journaling, and dot-voting to prioritize topics — applying Agile prioritization to learning and building shared vocabulary and peer accountability without managerial hierarchy.

On authority, a companion post argues relevance does not measure believability. Source authority is largely available from existing metadata, and graph centrality propagates trust like PageRank propagates web importance. But corroboration across independent witnesses differs from structural authority, and a static trust score can confidently suppress a stale-but-correct source, so contradictions should be surfaced rather than auto-resolved.

## Key Claims

- Values without structure produce uneven, non-compounding learning
- Semester-based global courses plus quarterly local cohorts with journaling
- Dot-voting applies Agile prioritization to learning topics
- Authority is a property of the source, mostly free from existing metadata
- Graph centrality propagates trust like PageRank propagates web importance
- A static trust score can confidently suppress a stale-but-correct source
