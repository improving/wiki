# Hedden Information Management

Hedden Information Management is an information-management consultancy associated with taxonomy and search practice. In this corpus its work frames why classification and retrieval systems decay: structure that depends on human upkeep fails, while structure generated as a pipeline side effect survives.

## Overview

- Taxonomies break when an item has more than one true parent, a common case in real content.
- Ontologies are powerful but expensive to build and maintain.
- Folksonomies scale but produce vocabulary mismatch between what people type and what is stored.
- Tags generated as a pipeline side effect survive; manually maintained tags decay.
- The companion retrieval argument: a shared drive and folder tree is a place to put things, not a retrieval system, and the real search index is usually a person.
