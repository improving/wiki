# James Duong

James Duong is a database and data-engineering specialist who appears in this corpus as the subject of Improving's roundup on Apache Arrow Flight SQL. A co-founder of [Bit Quill Technologies](/entities/bit-quill.md) and a contributor to [Dremio](/entities/dremio.md), he has spent over 15 years working on databases — from query engines to drivers and wire protocols — and has become an industry voice on Arrow's columnar data-access interfaces.

## Work

- Co-founded Bit Quill Technologies, the Vancouver data-and-cloud consultancy [Improving](/entities/improving.md) later acquired.
- Contributes to Dremio and to Apache Arrow itself, specializing in drivers and data-transfer protocols.
- Has worked with databases for more than 15 years across query engines, drivers, and protocols.

## Apache Arrow Flight SQL

- Presents Arrow Flight SQL as a roughly 20x faster alternative to JDBC and ODBC.
- Flight SQL is usable from Python, C++, Java, and other languages.
- A JDBC driver built on Flight SQL lets existing applications such as Tableau gain the speedup with no application changes.
- His talks span Subsurface's Cloud Data Lake Conference, Voltron Data's Data Thread Conference, and the GrayBeardsOnStorage podcast, where Arrow Flight is described as interfaces and services that parallelize loading and unloading Arrow data over the network.
