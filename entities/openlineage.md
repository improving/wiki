# OpenLineage

OpenLineage is an open standard for collecting data lineage metadata, advanced as the vendor-neutral answer to a fragmented lineage tool market. It appears in the corpus as the emerging standard for capturing how data moves and changes, including in real-time streaming pipelines.

## Key Facts

- OpenLineage is a graduated Linux Foundation AI & Data project, offering a standardized, technology-agnostic, real-time-suitable format with growing producer and consumer support.
- It is listed among governance and lineage tooling alongside Azure Purview, AWS Glue Data Catalog, and Apache Atlas.
- A reference architecture extends OpenLineage's run/job/dataset model to run, agent, prompt, and model so AI assets are governed in the same estate as data assets.
- The corpus notes the broader lineage market is fragmented — organizations run 3–20 products with no single pane of glass — which is the gap OpenLineage is meant to close.
