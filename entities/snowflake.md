# Snowflake

Snowflake is a cloud data platform that this corpus uses as the setting for arguments about governance, catalogs, and data quality — above all, that embedding governance in the pipeline beats bolting it on.

## Overview

The posts argue governance programs failed because policies lived as documents: only 8% of organizations rated their data governance programs highly successful in 2020, and the top barriers were behavioral, not budgetary. Bolt-on governance left catalogs stale and unused because curation was manual. Gartner's arc reinforces the shift, replacing its metadata management quadrant with a governance platforms quadrant and positioning AI-augmented catalogs as a runtime control plane. On quality, 74% of data professionals say stakeholders catch issues before the data team, so testing must run as code with clear ownership.

## Key Claims

- Only 8% of organizations rated their data governance programs highly successful in 2020
- Top governance barriers were behavioral: policy adherence and usability, not budget
- Gartner replaced its metadata management quadrant with a governance platforms quadrant
- AI-augmented catalogs generate metadata and execute policy at runtime
- 74% of data professionals say stakeholders catch data quality issues before the data team
