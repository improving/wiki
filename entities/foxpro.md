# FoxPro

FoxPro is a legacy rapid-application-development (RAD) database that appears in this corpus as a case study in why "legacy" should not be an insult. It is cited as one of the tools mainframe-era engineers dismissed as "cheating," yet applications built with it ran businesses for decades.

## Role in the Corpus

- FoxPro and [Microsoft Access](/entities/microsoft-access.md) applications built with RAD were dismissed as cheating by mainframe-era engineers, yet some ran businesses for decades.
- The pattern repeats each generation: Visual Basic was "too simple" for C++ developers, .NET "too abstracted" for VB developers, and now AI-assisted development gets the same skepticism.
- A system that survived fifteen years is evidence of success, not failure; the problem is approaching it with contempt instead of curiosity.
