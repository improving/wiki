# Scrum.org

Scrum.org is the training, certification, and advocacy organization for Scrum, known for its Professional Scrum curriculum and the Professional Scrum Master assessments. Its artifacts and guidance recur in this corpus as the scaffolding for debt reduction and shared testing practice.

## Overview

One post maps Dave Ramsey's seven baby steps onto technical debt: stop creating new debt through a strong Definition of Done, build a test safety net before fixing legacy problems, then invest in skills, behavior testing, and designing for the future. The other lays out four principles for treating testing as a first-class, shared practice — everyone owns UI automation, shared test code is production code, all developers can read and write tests, and building/deploying/testing should be "stupid easy."

## Key Claims

- Technical debt is trading craftsmanship for short-term velocity
- A strong Definition of Done is how a team stops creating new debt
- Build a safety net of tests before attacking legacy problems
- Shared test code is production code and held to the same standards
- Building, deploying, and testing should be stupid easy so it happens consistently
