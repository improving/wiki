I had the opportunity to host a series for our company, [Improving](https://improving.com/?ref=driventodevelop.com), called "Ship Faster With AI." In the series, we are adding a feature to our internal platform, Engage, using our AI tooling in real-time to build it. It's a fun way to show off what we use in our roles as consultants, without it being a bland demo (Hello, World, anyone?) that's not really applicable to anyone.

We started with the state of AI. Bill Curry joined me, and it was a great conversation and a level-set for the series. You can watch it here: [https://www.youtube.com/watch?v=OMBJCdDOQ64](https://www.youtube.com/watch?v=OMBJCdDOQ64&ref=driventodevelop.com)

Then David Sandoval joined me to show his UI/UX skills and the tools we've been using to accelerate our teams and clients. Here is that episode: [https://www.youtube.com/watch?v=XEyViSvOABI](https://www.youtube.com/watch?v=XEyViSvOABI&feature=youtu.be&ref=driventodevelop.com)

Next up, Eric Seibenich showed off Windsurf and the features we use in the AI-enabled IDE to write code and build the feature. I learned quite a few new tricks in this one, and you can too by watching it here: [https://www.youtube.com/watch?v=13950YRvs7U](https://www.youtube.com/watch?v=13950YRvs7U&ref=driventodevelop.com)

Aman Juneja showed us how we can build prompts and scripts to build environments, deploy and validate packages, and make sure we're aligning on things like compliance as we put our feature into production. It was a deeper dive into ways that we can capture infrastructure and documentation as we go; check it out: [https://www.youtube.com/watch?v=o_E3e2yNrzI](https://www.youtube.com/watch?v=o_E3e2yNrzI&ref=driventodevelop.com)

Finally, Rich McCraw showed how we can use data analysis tools to gather analytics and insights from the system itself. Watch here: [https://www.youtube.com/watch?v=cssdagZmII4](https://www.youtube.com/watch?v=cssdagZmII4&ref=driventodevelop.com)

For me, this series was a lot of fun as I got to get close to the work that we do as consultants (something I haven't done much of in the past number of years) and walk alongside as I learned new tools and techniques leveraging AI. I'm super energetic about where we are as an industry and all the interesting things that are coming in our space.
