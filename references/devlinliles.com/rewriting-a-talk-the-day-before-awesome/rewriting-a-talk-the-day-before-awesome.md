So this morning I get to the office at a brisk 6:30. I sit down with my MSDN forum haze on and start sipping my plantation mint tea. I flip open my Google Reader and BOOM — right there on the Gu's blog is the announcement of CTP5 of Entity Framework Code-First. My talk this Thursday is on POCO separation and Entity Framework. The light above me comes on, and angels sing. This is the moment in which I realize that I have 4–5 hours of work until I can have something truly awesome: a great talk that is both on topic and timely with the latest technology.

It is times like these that I think Microsoft is conspiring to make my life great. So off I go to rewrite my talk to use the latest CTP and the nifty new features. If you want to read the full write-up:

[Announcing Entity Framework Code First CTP5 Release](https://weblogs.asp.net/scottgu/announcing-entity-framework-code-first-ctp5-release/?ref=devlinliles.com)

Gotta love it when the plan gets blown away and replaced by a better plan!
