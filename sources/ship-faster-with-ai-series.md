# Ship Faster with AI Series — Summary

**Original source**: `references/driventodevelop.com/ship-faster-with-ai-series/ship-faster-with-ai-series.md`

## Summary

O'Hara recaps hosting an Improving video series, "Ship Faster With AI," in which the team adds a feature to the internal platform Engage using their AI tooling in real time. He frames it as a way to show what consultants actually use day to day, deliberately avoiding a bland, non-applicable demo. The post lists each episode and guest: Bill Curry on the state of AI, David Sandoval on UI/UX tools, Eric Seibenich on Windsurf in the AI-enabled IDE, Aman Juneja on prompts and scripts for environments, deployment, validation, and compliance, and Rich McCraw on data analysis for insights.

## Key Claims

- The series builds a real feature on Engage rather than running a throwaway demo.
- The opening state-of-AI conversation with Bill Curry level-sets the series.
- Guests cover UI/UX acceleration, AI-enabled IDE coding with Windsurf, and infrastructure/deployment scripting.
- Prompt and script work also captures infrastructure and documentation and aligns compliance.
- Data analysis tools pull analytics and insights from the system itself.
