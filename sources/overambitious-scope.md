# Top 10 Reasons AI Projects Fail #6: Overambitious Scope — Summary

**Original source**: `references/improving.com/overambitious-scope/overambitious-scope.md`

## Summary

Ambition is not the problem; unbounded ambition is. Teams that try to deliver an "enterprise brain" in phase one produce sprawling roadmaps, delayed decisions, and pilots that never ship because they are never quite perfect. The fix is to translate vision into velocity: scope narrowly, ship measurable value in twelve weeks, and let each phase fund the next.

## Key Claims

- The classic failure quote: "Trying to deliver an entire enterprise brain in phase one… the pilot never ships because it's not quite perfect."
- Four causes: unbounded vision, perfection over progress, unclear user value, and a weak decision cadence without checkpoints.
- Scope for a 12-week win that delivers measurable value within three months.
- Define a thin vertical slice: one job to be done, one user group, one quantifiable outcome.
- Ship behind feature flags and A/B test impact on KPIs; establish kill criteria and review decisions every two to three sprints.
- Apply crawl-walk-run so value is proven before functionality expands.
- Example: an underwriting assistant that summarized three documents cut review time 25%; later phases added policy lookups and exception handling.
