# Modernizing ETL Pipelines: Why Enterprises Are Migrating from Informatica to Confluent & Databricks — Summary

**Original source**: `references/improving.com/etl-modernization-informatica-to-confluent-databricks/etl-modernization-informatica-to-confluent-databricks.md`

## Summary

Sarthak Routh argues that legacy batch ETL platforms such as Informatica have become bottlenecks, and that migrating to Confluent and Databricks unlocks real-time streaming and analytics. He lists Informatica's challenges — complex integrations, scalability limits, operational overhead, limited real-time capability, and governance gaps — then outlines Improving's migration framework from assessment through code modernization, real-time enablement, integration, and governance. The pitch closes with Improving's Confluent Elite Systems Integrator credentials and industry track record.

## Key Claims

- Legacy ETL was designed for manageable data volumes and overnight batches; today real-time analytics is a competitive necessity.
- McKinsey is cited that by 2025 nearly all employees will use data to optimize work, and real-time-embedded organizations will outperform peers.
- Informatica challenges: tightly coupled integrations, costly scaling, high on-premises operational overhead, batch delays, and weak built-in governance.
- The migration framework covers assessment and planning, code and process modernization (using Code Explorer), real-time enablement via Confluent Cloud, seamless integration with connectors, and security and governance from day one.
- Databricks' lakehouse supports advanced analytics, AI/ML, and secure data collaboration; Confluent supplies managed streaming without legacy operational burden.
- BCG is cited that companies using real-time analytics and cloud-native platforms are 2.5 times more likely to report significant decision-making improvements.
- Improving cites $40M+ in event streaming solutions since 2013, 2,400+ consultants, and end-to-end service; co-authors are Alex Brekken, Nick Larson, and Mark Soule.
