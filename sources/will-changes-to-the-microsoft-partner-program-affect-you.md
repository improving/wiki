# Will Changes to the Microsoft Partner Program Affect You? — Summary

**Original source**: `references/improving.com/will-changes-to-the-microsoft-partner-program-affect-you/will-changes-to-the-microsoft-partner-program-affect-you.md`

## Summary

Microsoft is rebranding its partner program and changing how partners are measured, but the post argues this matters less to buyers than how they actually select a partner. Since the technology is identical across partners, the real differentiator is what a partner can do with it — and deals are won on trust, referrals, industry expertise, and size.

## Key Claims

- Microsoft is rebranding the Microsoft Partner Network and launching the Microsoft Cloud Partner Program (MCPP) in October 2022, affecting 400,000 global partners.
- Buyers tend to weight a partner's competencies low, partly because it is hard to differentiate one Microsoft gold partner from another.
- If the technology is the same for every partner, the differentiator is what the partner can do with it.
- The top four reasons partners win deals: trust (already delivered for a client), transferable trust (referrals), industry expertise, and size/breadth of capability.
- Location and price matter less than these; location is largely a non-issue and the cheapest option often costs more long term.
- A Microsoft label still validates a partner's skill set, but it is seldom the driving factor in selection.
