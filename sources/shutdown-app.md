# "Shutdown App" - The Latest Application to Our Mine Analytics Playbook — Summary

**Original source**: `references/improving.com/shutdown-app/shutdown-app.md`

## Summary

Improving built a Shutdown App for mining and heavy-asset industries, planning scheduled maintenance shutdowns with an integrated project plan, worker assignment, configurable checklists, and real-time dashboards.

## Key Claims

- Mine sites periodically hold planned shutdowns for maintenance, and every idle hour costs operators thousands of dollars in potential revenue.
- The app integrates an MS Project plan with a customized worker directory for assigning tasks.
- Custom shutdown planning checklists can be modified for each shutdown event, from lead-up to close-out.
- Workflows and dashboards enable real-time tracking.
- It was built on Microsoft Azure Analytics and Power Platform and joins Improving's Mine Analytics playbook.
