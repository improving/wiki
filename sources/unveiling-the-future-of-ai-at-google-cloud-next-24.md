# Unveiling the Future of AI at Google Cloud Next '24 — Summary

**Original source**: `references/improving.com/unveiling-the-future-of-ai-at-google-cloud-next-24/unveiling-the-future-of-ai-at-google-cloud-next-24.md`

## Summary

An Improving attendee summarizes Google Cloud Next '24 (Las Vegas, April 9–11, 2024). The post highlights JAX for high-performance accelerator computation, embeddings now available across databases and in multimodal form, the Gemini 1.5 preview with up to 1M input tokens, and GCP Workflows connectors that call Generative AI APIs directly.

## Key Claims

- Google Cloud Next '24 ran April 9–11, 2024, in Las Vegas.
- JAX is a NumPy-based Python framework for accelerator-oriented array computation, claimed to outperform TensorFlow and PyTorch for training speed.
- Embeddings are now available across all databases, including multimodal embeddings for vector search, recommendations, and sentiment analysis.
- Gemini 1.5 preview is multimodal across images, audio, video, text, and PDFs with up to 1M input tokens, and can return chapters with timestamps from media.
- GCP Workflows, a YAML-described orchestration tool, gained connectors to call Generative AI APIs directly.
- The post frames these as enabling Improving to build AI-based applications on GCP for clients.
