# New Feature in SAP Analytics Cloud: Best Performance Tips — Summary

**Original source**: `references/improving.com/new-feature-in-sap-analytics-cloud/new-feature-in-sap-analytics-cloud.md`

## Summary

SAP's Q4/2021 release added Best Performance Tips to SAP Analytics Cloud, surfacing non-blocking hints to Story builders when design choices risk slowing a Story down. The post explains the feature and flags a less-publicized reminder to keep the SAP Cloud Connector and Cloud Agent updated.

## Key Claims

- Best Performance Tips appear to Story builders when certain conditions are met, but only in Edit mode.
- Tips never prevent an action; they prompt review of layout alternatives or splitting content into separate Stories linked by hyperlinks.
- Example: exceeding a page-count threshold warns that more pages could impact performance.
- The same guidance applies to input control filters and the number of elements on a page.
- SAP Cloud Connector and SAP Cloud Agent connect SAC to internal systems but do not auto-update; companies should create a process to check for updates.
- Keeping those tools current lets users benefit from SAC's performance upgrades when retrieving data from internal systems.
