# Tags Are a Promise Nobody Enforces — Summary

**Original source**: `references/devlinliles.com/tags-are-a-promise-nobody-enforces/tags-are-a-promise-nobody-enforces.md`

## Summary

Traces why enterprise tagging drifts from description to decoration, arguing the failure is structural rather than disciplinary. It compares the three classification models — taxonomy (single hierarchy), ontology (typed relationship web), and folksonomy (free-form tags) — and shows each breaks in a predictable place. The deeper problem is that all three assume a person will maintain tags after launch, invisible work that gets skipped under deadline pressure.

## Key Claims

- A taxonomy breaks when an item has two true parents; a half-built ontology is worse than a maintained taxonomy; a folksonomy produces the vocabulary mess anyone would predict.
- Tagging is real judgment and time spent on work with no visible output, so it decays on a predictable schedule.
- The fix is active metadata: a governance tool like Collibra wired into the pipeline so tags are populated as a side effect of the pipeline running.
- A tag a system generates survives; a tag that depends on someone remembering decays.
- None of the three models solves vocabulary mismatch, which requires a different retrieval method entirely.

## Relevance

Informs enterprise AI retrieval and [data governance](/concepts/data-governance.md), setting up [active metadata](/concepts/active-metadata.md) as the durable alternative and pointing to [vocabulary mismatch](/concepts/vocabulary-mismatch.md) as the next problem.
