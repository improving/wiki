# Think Differently About Data — Summary

**Original source**: `references/improving.com/think-differently-about-data/think-differently-about-data.md`

## Summary

What separates a tech company from a traditional one is treating data as usage patterns, interactions, and infrastructure load rather than only the information users explicitly provide. The post argues that storing that latent data cheaply enough now makes recommendations, smarter workflows, and operational savings reachable.

## Key Claims

- Most systems store only required user data, ignoring access patterns, performance metrics, and operational parameters.
- Storing search queries, viewed items, and abandoned carts enables recommendations that raise completed transactions.
- Parsing receipts and recording user corrections can auto-suggest expense categorizations that improve over time.
- Cloud storage runs about $0.022 per GB per month, so 1 TB costs roughly $264 per year.
- 1 TB can hold about 500,000 images or 62.5 billion timestamped high-precision sensor readings.
- Fleet telemetry of 1.5 MB per van per year means 1 TB covers 10,000 vans for 66 years, and a 10% fuel saving on one van (~$1,092/year) covers the whole fleet's storage.
