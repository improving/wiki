# Starting Out in Ruby — Summary

**Original source**: `references/devlinliles.com/starting-out-in-ruby/starting-out-in-ruby.md`

## Summary

A short apprenticeship log: Devlin Liles begins learning Ruby and records the paradigms that surprised his statically typed background. Extending a class to add a class-scoped method, and overriding constructors to return something other than the class being constructed, both made his "statically typed brain hurt." He closes by outlining a study schedule and thanking his mentor.

## Key Claims

- Ruby lets you append a class-scoped (static) method to an existing type, for example a `Guid`.
- Constructors can be overridden to return objects other than the class being constructed, which makes factories and abstract factories language-supported constructs.
- He plans to work through the Ruby Koans, then build a console game (Zork-like) to learn idiomatic Ruby rather than "C# in Ruby."
- Progress is tracked publicly on GitHub.
