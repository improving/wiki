# Leveraging SAP Analytics Cloud with SAP BusinessObjects — Summary

**Original source**: `references/improving.com/leveraging-sap-analytics-cloud-with-sap-businessobjects/leveraging-sap-analytics-cloud-with-sap-businessobjects.md`

## Summary

As most IT moves to the cloud, SAP BusinessObjects customers should gradually shift capabilities to SAP Analytics Cloud, which delivers cloud data visualization, planning, and predictive analytics as SaaS. The post explains why to integrate the two tools and how SAC complements BOBJ and SAP BPC.

## Key Claims

- SAC is an all-in-one SaaS product for data visualization, budget planning, and predictive analytics; BOBJ is SAP's on-premises BI reporting suite.
- Legacy Explorer and Xcelsius dashboards will be obsolete in the short term and should start moving to SAC.
- BOBJ capabilities such as Analysis for Office, Lumira Designer, and scheduling/bursting are available in SAC; keep Universe, Web Intelligence, and Crystal Reports only if critical.
- SAP extended BusinessObjects maintenance to 2027 to protect customer investments and plans cloud transition scenarios.
- SAC adds Automated Insights through Augmented Analytics, using AI/ML to discover deep insights and support decisions.
- With BPC, planning can reside in SAC (importing actuals and using predictive planning) or in BPC (with SAC executing planning sequences); BPC Embedded exploits HANA while BPC Standard is still evolving there.
