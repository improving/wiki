# Why Improving Uses Scala — Summary

**Original source**: `references/improving.com/why-improving-uses-scala/why-improving-uses-scala.md`

## Summary

Sarthak Routh introduces Scala as a statically typed JVM language that combines object-oriented and functional programming, created by Martin Odersky in 2004. He details its benefits — scalability, type safety, Java interoperability, functional programming, concise syntax, and community support — and its use cases in big data, web, machine learning, and finance. Improving uses Scala with Akka to modernize monoliths into distributed cloud-native applications on a Reactive architecture.

## Key Claims

- Scala was created by Martin Odersky in 2004 to show that object-oriented and functional programming can be fused practically.
- Benefits include scalability, static type safety, Java interoperability, immutable data and pure functions, concise syntax, and a large community.
- Scala's type system supports generics, variance annotations, type bounds, implicits, and polymorphic methods; errors surface at compile time.
- Scala is the preferred language for Apache Spark because its concise syntax and functional features simplify parallel, distributed code.
- Common use cases: big data processing, web development (Play, Akka HTTP), machine learning, fintech, and application modernization.
- Improving uses Scala and Akka to build distributed, resilient microservices for public sector, tourism, finance, and logistics clients, and engages the community at Scala Days.
