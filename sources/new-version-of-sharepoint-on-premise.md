# New Version of SharePoint On-Premise — Summary

**Original source**: `references/improving.com/new-version-of-sharepoint-on-premise/new-version-of-sharepoint-on-premise.md`

## Summary

Microsoft announced SharePoint On-Premise Server Subscription Edition (SE) in summer 2021 to serve organizations that still need on-premises SharePoint. The post highlights why teams should upgrade: a modern experience, continuous updates, easy upgrades, and TLS 1.3 support.

## Key Claims

- SharePoint Server Subscription Edition was announced in summer 2021 and entered public preview, aimed at on-premises users.
- SE ends the cycle of long, costly major version upgrades by delivering new features automatically through a subscription.
- It supports direct upgrades from SharePoint 2016 and SharePoint 2019, and 2016 can upgrade directly to SE without first moving to 2019.
- New features include OpenID Connect support, People Picker improvements, and updates to search, list items, and libraries.
- SE adds support for TLS 1.3, the latest version of the internet's most widely deployed security protocol.
