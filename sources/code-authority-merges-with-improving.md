# Code Authority Merges with Improving — Summary

**Original source**: `references/improving.com/code-authority-merges-with-improving/code-authority-merges-with-improving.md`

## Summary

Improving acquired Code Authority, a custom software development and digital marketing firm headquartered in Frisco, Texas, with an emphasis on entrepreneurship and startups. The merger continued Improving's "Enterprise Model" of combining like-minded service firms, and brought CodeLaunch — Code Authority's seed-accelerator and startup pitch competition — into Improving with plans to expand it to more markets.

## Key Claims

- Code Authority is headquartered in Frisco, Texas, and focuses on custom software, cloud, mobile, and digital transformation plus digital marketing and UI/UX.
- The deal continued Improving's "Enterprise Model," merging firms that share commitments to excellence, trust, and culture while keeping local ownership behavior.
- Code Authority's leadership, including President Jason W. Taylor, stayed on to keep operating and growing the business.
- Code Authority built CodeLaunch, a zero-equity seed-accelerator event pairing early-stage startup winners with developers, venture capitalists, and sponsors.
- Improving planned to accelerate CodeLaunch into additional markets.
- Code Authority had 18 years of organic growth; John Anderson credited its perseverance and drive.
- Taylor credited Frisco's pro-business infrastructure, chamber, EDC, and mayors for enabling the growth.
