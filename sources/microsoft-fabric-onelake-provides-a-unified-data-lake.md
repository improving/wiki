# Microsoft Fabric: OneLake Provides a Unified Data Lake — Summary

**Original source**: `references/improving.com/microsoft-fabric-onelake-provides-a-unified-data-lake/microsoft-fabric-onelake-provides-a-unified-data-lake.md`

## Summary

Microsoft Fabric brings several existing data products into one experience, and its new OneLake implements a unified data lake that combines files and structured sources with the users who can access them. Data is organized into business domains where governance and security apply, and sources can be endorsed to signal trust.

## Key Claims

- Fabric unifies Azure Synapse (querying), Azure Data Factory (ETL), and Power BI into a single experience; OneLake is the new unified lake piece.
- OneLake can link external sources such as Azure Data Lake, Databricks, and AWS to virtualize access and eliminate moving data.
- Data is organized into domains (Finance, Sales, Operations) where governance, security, and endorsement apply.
- Without governance, data lakes become chaotic — the author's "library without librarians" analogy.
- OneLake's Data Hub (in the Power BI/Fabric portal) lets users find, filter, and explore items they can access.
- Fabric pricing starts at about $292 per month for the smallest capacity and is not tied to user count, though Power BI Pro is still required per user.
