# 10 Advantages of Cloud Computing — Summary

**Original source**: `references/improving.com/10-advantages-of-cloud-computing/10-advantages-of-cloud-computing.md`

## Summary

Cloud computing lets organizations consume IT services on demand instead of owning and managing servers and data centers. The post defines the IaaS, PaaS, and SaaS models and lists ten reasons to adopt the cloud, from pay-as-you-go pricing to built-in disaster recovery.

## Key Claims

- Cloud computing uses the internet to access a provider's computing infrastructure instead of owning physical servers and data centers.
- The three models are IaaS, PaaS, and SaaS, running from most self-managed to least, with PaaS described as a hybrid.
- Pay-as-you-go lets businesses start small and scale up or down without sunk cost in on-premises hardware.
- Providers handle maintenance, security, disaster recovery, and updates, reducing the need for in-house IT experts.
- Cloud enables remote access, collaboration, and data sharing, which mattered through COVID-19.
- Common providers include AWS, Google Cloud Platform, Azure, and Office 365.
