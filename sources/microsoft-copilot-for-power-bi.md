# Microsoft Copilot for Power BI — Summary

**Original source**: `references/improving.com/microsoft-copilot-for-power-bi/microsoft-copilot-for-power-bi.md`

## Summary

Kyle Thorburn reports on Microsoft 365 Copilot demos at the M365 Conference in Las Vegas, where natural language could generate Power BI reports and answer questions like "Why was profit down in Q1 of 2022?" He argues the real barrier to reporting is rarely report-writing skill but the absence of a usable data model, and that organizations must build those models before Copilot can help.

## Key Claims

- Copilot translates natural-language questions into a Power BI query, builds reports, performs analysis, and returns a visual report.
- Example prompts include "Show me revenue trends by quarter for the last 5 years."
- Improving finds nearly 100% of clients seeking report help actually have a data model problem, not a report-writing problem.
- Analysts often patch data together in Excel until the sheet stops working as a maintainable model.
- Copilot lowers the report-building skill bar but still requires a data model containing the right artifacts, organized for analysis.
- Preparation means inventorying current data sources and building meaningful models over disparate sources and data lakes.
