# Using Data to Make Informed Decisions — Summary

**Original source**: `references/improving.com/using-data-to-make-informed-decisions/using-data-to-make-informed-decisions.md`

## Summary

Businesses generate data constantly — from decisions, customer interactions, sales, projects, and change orders — stored across notes, ledgers, artifacts, and repositories. Capturing it is not enough: it must be transformed from its raw state, identified, evaluated, and stored so it survives the people and projects that produced it, and it must be accessible, relevant, and accurate. CRM, ERP, knowledge-management, and collaboration tools each hold part of the picture, but cross-system search is hard. LLMs and tools like Improving's Echo make natural-language, cited search possible while keeping data in-house.

## Key Claims

- Data is generated at every step — decisions, customer interactions, sales, projects, change orders, and internal initiatives.
- Captured data is useless unless it can be found, retrieved, and turned into actionable business intelligence.
- Information must be transformed from its raw state and must be accessible, relevant, and accurate.
- Data must be preserved so it does not disappear when the projects and people associated with it do.
- CRM, ERP, knowledge-management, and collaboration tools each cover specialized pieces but create cross-system search problems.
- LLMs offer natural, context-aware search across sources; Echo summarizes disparate data with citations and without hallucination, keeping data in-house to protect sensitive information.
