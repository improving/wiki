# The Project Manager's Evolution, Stage 3: Encoding the Craft — Summary

**Original source**: `references/devlinliles.com/the-project-managers-evolution-stage-3-encoding-the-craft/the-project-managers-evolution-stage-3-encoding-the-craft.md`

## Summary

Stage 3 of the [AI maturity model](/concepts/ai-maturity-model.md) is where the project manager stops merely using an assistant and starts encoding their own delivery craft into personal agents. An agent or skill is a written job description for a unit of work: how to turn scope into a credible schedule, how to build a risk register that names real risks, how to read raw updates into an honest status. This externalizes instinct into [encoded standards](/concepts/encoded-standards.md) the team can finally share. The PM's day shifts from assembling artifacts to defining intent and judging output.

## Key Claims

- Once a standard is encoded, it applies to every artifact the agent produces, not one report, so fuzzy definitions of "on track" must be right.
- A strong Stage 3 is held to a low-nineties acceptance rate on agent output; below that the standard or context is weak, above it the PM is rubber-stamping.
- Directing agents resembles managing people, but agents invert the failure profile: they can handle complex work correctly yet misread simple projects with total confidence.
- The ceiling is that everything is still personal: five PMs still mean five definitions of "on track," which Stage 4 must reconcile.

## Relevance

Informs the [AI maturity model](/concepts/ai-maturity-model.md) and the [Confidence-Correctness Gap](/concepts/confidence-correctness-gap.md) as it applies to delivery judgment.
