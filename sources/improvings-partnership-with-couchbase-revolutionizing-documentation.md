# Improving’s Partnership With Couchbase: Revolutionizing Documentation With An AI Chatbot — Summary

**Original source**: `references/improving.com/improvings-partnership-with-couchbase-revolutionizing-documentation/improvings-partnership-with-couchbase-revolutionizing-documentation.md`

## Summary

Improving Vancouver partnered with Couchbase to build an AI chatbot that replaces menu navigation and keyword search with natural-language questions over technical documentation. Built on AWS Bedrock and LangChain, it aims to speed developer onboarding and update automatically as docs change.

## Key Claims

- Couchbase's conventional navigation and keyword search no longer met developer expectations, prompting a GenAI-based documentation chatbot.
- The chatbot was built on AWS Bedrock LLMs with Python and Vue for backend glue code and front end.
- LangChain turns each user question into a prompt and returns a contextually relevant response in plain language.
- The chatbot reacts instantly to documentation changes, removing manual knowledge-base updates and reducing errors.
- Key lessons: define success criteria from the start; LLMs do not always answer identical questions identically, so evaluation accounted for that variability; and ongoing iteration is required as user behavior and system performance become clearer.
