# A Guide to Kanban Certification Training (APK/PSK) — Summary

**Original source**: `references/improving.com/guide-to-kanban/guide-to-kanban.md`

## Summary

A two-day Kanban class will not make anyone an expert, but the APK and PSK courses still build a foundational understanding through discussion, discovery, and shared experience. The post explains what each class covers and how to choose: PSK for teams already practicing Scrum, APK for anyone applying Kanban on its own.

## Key Claims

- Neither Applying Professional Kanban (APK) nor Professional Scrum with Kanban (PSK) makes someone an expert, but both build foundational understanding.
- APK is sourced from The Kanban Guide (ProKanban.org); PSK is sourced from The Kanban Guide for Scrum Teams (Scrum.org).
- Both bodies reject prescriptive approaches because team context varies, offering minimal practices teams build on.
- PSK assumes existing Professional Scrum knowledge; APK requires no Scrum prerequisite and stands alone as a Kanban system.
- PK I and PSK I certifications never expire and carry no ongoing fee, and both bodies offer free open assessments.
