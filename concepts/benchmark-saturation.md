# Benchmark Saturation

Benchmark saturation is what happens when models score so high on a benchmark that the remaining differences no longer distinguish capability. Across this corpus it is treated as an epistemic problem — once a benchmark saturates, the claims built on it stop being falsifiable and the competitive field shifts elsewhere.

## Key Claims

- A claim is scientific only if it is falsifiable, per Popper; a saturated benchmark no longer supports falsifiable capability claims.
- MMLU saturated above 88 to 90 percent, making score gaps statistically meaningless.
- Contamination inflates scores, and decontamination removes roughly 23 percent of MMLU inflation.
- Top model benchmark scores have compressed to within a point of each other, so frontier capability no longer sorts the field.
- As scores converge, labs with enterprise and government exposure compete on governance credentials instead — for example, Anthropic naming a career jurist as its first Chief Global Affairs Officer and AWS making zero data retention the default on Bedrock.
- Aviation safety certification is cited as a precedent for governance becoming the deciding axis.
- Organizations should build internal, falsifiable eval suites drawn from real use cases.
