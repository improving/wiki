# Shared vocabulary

Shared vocabulary is the set of named concepts a team can reason with. The corpus treats it as infrastructure rather than decoration: teams cannot think efficiently about ideas they cannot name, so naming recurring patterns and problems is high-leverage technical-lead work. It also compounds — a vocabulary built over years speeds every later architectural discussion.

## Key Claims

- Teams cannot think efficiently about ideas they cannot name.
- False dichotomies persist when the synthesis that resolves them has no name.
- Shared vocabulary compounds, speeding architectural discussion over years.
- Technical leads should name recurring patterns and problems as part of the job.
- Structured learning cohorts build shared vocabulary and peer accountability without relying on managerial hierarchy.
- Values without structure produce uneven, non-compounding learning across an organization.
