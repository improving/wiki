* [UX Maturity](./ux-maturity.md) - How deeply an organization treats design as a strategic capability rather than an afterthought.

* [vibe coding](./vibe-coding.md) - Building software by prompting an AI without structured context, which trades short-term speed for drift.
* [Virtuous Cycle](./virtuous-cycle.md) - A self-reinforcing loop in which a small good action produces conditions that make the next one easier.
* [Vocabulary mismatch](./vocabulary-mismatch.md) - When a query and a document mean the same thing but share no words, defeating keyword search and manual tags.

* [work-life balance](./work-life-balance.md) - The idea that work and family time should be balanced; these sources argue balance is the wrong frame.
* [workflow sequencing](./workflow-sequencing.md) - Ordering which workflows to automate first, earning confidence by proving each protection harness gate holds.
* [Working Memory](./working-memory.md) - The active, retained context an agent holds during a task — a designed mechanism, not a bigger context window.
* [zero trust security](./zero-trust-security.md) - Verifying every request as if the network is already breached, with least privilege and continuous checks.
