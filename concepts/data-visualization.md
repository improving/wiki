# data visualization

Data visualization is the design of charts and interfaces that let people explore and understand data. This corpus treats it as an analytics-specific UX problem: unlike a typical web experience that funnels users down one path, a data product must support branching exploration, and chart choice should follow how human perception actually works.

## Key Claims

- Traditional user-flow rules — one clear purpose, a single guided path, demonstrated task completion — break down when the goal is exploration; a dashboard's charts × filters × sortable fields and toggles become a maze of divergent paths ([part 1](/sources/creating-better-data-visualization-experiences-part-i.md)).
- UX has shifted from personality-based personas toward task-based framing, with many experts favoring Jobs to Be Done; discovery via user interviews, empathy mapping, and user stories surfaces the questions users arrive with ([part 1](/sources/creating-better-data-visualization-experiences-part-i.md)).
- Humans estimate length and position in two dimensions well but judge angles, area, and color poorly — so pie charts, which encode a value three ways, compare badly ([part 2](/sources/creating-better-data-visualization-experiences-part-ii.md)).
- Dashboards compound the perception problem: many charts on one page, changing rapidly, make information harder to discern ([part 2](/sources/creating-better-data-visualization-experiences-part-ii.md)).
- BI splits into reporting systems and interactive self-service analytics; data storytelling connects the two and helps people collaborate ([part 2](/sources/creating-better-data-visualization-experiences-part-ii.md)).
- Library selection should weigh customization, rendering method, learning curve, support/documentation, and interactivity — driven by how users intend to use the tool, not just its features ([part 2](/sources/creating-better-data-visualization-experiences-part-ii.md)).
- Power BI ships standout visuals: natural-language Q&A (recognized words underlined in blue, low-confidence in orange), Key Influencers (age 47–90 makes high income 11.96× more likely), and Smart Narratives that generate editable prose ([Power BI walkthrough](/sources/data-analysis-and-visualization-with-microsoft-power-bi.md)).
