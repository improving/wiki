# Skill Discovery

Skill discovery is the problem of finding the right agent skill when it is needed. The corpus's central claim is that a SKILL.md is structurally just another knowledge object — so the discovery and retrieval problems already known for documents repeat verbatim at the skill layer. Distribution is largely solved; discovery still lacks authority.

## Key Claims

- A SKILL.md is structurally a knowledge object someone must find at need.
- Progressive disclosure loads name and description first, body and scripts later.
- SkillsBench scored 47,150 public skills at 6.2 out of 12 average quality.
- Curated, reviewed skills raised pass rates 16.2 points — 51.9 points in healthcare.
- Over 2,500 Claude Code plugin marketplaces exist with no trust authority.
- Documents and skills fail discovery for the same structural reason; the goal is one governed catalog answering current, owned, safe-to-use.
