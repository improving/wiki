# Distributed cognition

Distributed cognition is [Edwin Hutchins'](/entities/edwin-hutchins.md) theory that intelligence is not confined to an individual mind but is spread across people, tools, and protocols. Across this corpus it is the frame for evaluating AI: a model is a new class of node in a cognitive system, and its value depends on how well the system is designed around it.

## Key Claims

- Intelligence lives across people, tools, and protocols, not inside any single node.
- AI adds a new class of node whose effect depends on integration, not model capability.
- Treating AI as a productivity add-on speeds individual nodes without improving the system.
- The useful question is how well the system is designed, not how smart the model is.
- Version control, tests, and CI/CD externalize and preserve team knowledge beyond individuals — they are [cognitive scaffolding](/concepts/cognitive-scaffolding.md).
- Deploying agents without governance scaffolding repeats the CI-without-quality-gates mistake.
