# Definition of Done

A Definition of Done is the explicit, agreed bar a change must clear before the team calls it finished. Across this corpus it is framed as the primary control on [technical debt](/concepts/technical-debt.md): debt accumulates when work is declared done while quality practices are skipped.

## Key Claims

- Technical debt is trading craftsmanship for short-term velocity; a strong Definition of Done is how you stop creating new debt.
- Build a safety net of tests before fixing legacy problems, then hold new work to the bar.
- Debt comes from continually trading craftsmanship for velocity, not from one bad decision; accumulation compounds.
- "Pay it back later" rarely happens, so prevention beats remediation.
- The root cause is behavioral with technical symptoms — a Definition of Done is a cultural control, not a tool.
- AI accelerates debt accumulation when quality standards are absent.
