# Data Ownership

Data ownership is the assignment of named, accountable responsibility for a dataset — its schema, quality, and service levels. Across this corpus it appears as the precondition that makes every other data discipline work: without an owner, contracts have nobody to enforce and observability has nobody to alert.

## Key Claims

- A [data contract](/concepts/data-contract.md) forces ownership and accountability as a precondition; enforcement at the producer shifts accountability from consumers to producers.
- 74% of data professionals say stakeholders catch data quality issues before the data team does — a symptom of ownership gaps.
- Manual data testing scales with engineering time while the data estate grows faster, so governance must run as code.
- dbt Core v1.5 access, contracts, and versions enforce governance at build time.
- Observability without defined ownership turns a fifteen-hour incident into a week.
