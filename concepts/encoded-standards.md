# encoded standards

Encoded standards are the step from using AI tools to building them: capturing an individual's judgment, review criteria, and craft as reusable agents and rules that produce consistent output for everyone. Across this corpus it is the boundary between Stage 2 maturity, where gains are personal and ephemeral, and Stage 3, where capability compounds across a team.

## Key Claims

- Most of the industry currently sits at Stage 2, where every gain is personal and ephemeral, so the team cannot compound learning.
- Engineers must move from using the tools to building the tools.
- Encoded standards make one PM's judgment repeatable across every agent output.
- Stage 3 targets a low-nineties acceptance rate on agent output.
- Agents fail differently: confidence decouples from correctness, so encoding must include verification.
- Personal agents leave five PMs with five definitions of "on track."
