# task agents

Task agents are narrow, personal agents that take on a single unit of work — encoded with one engineer's judgment and standards — while the engineer shifts from producing code to directing intent and reviewing output. In this corpus they mark Stage 3 of an AI trust journey, the point where delegation becomes real and the reviewer's job changes shape.

## Key Claims

- Stage 3 agents are personal: they encode one engineer's judgment and standards rather than a team-wide policy.
- A skill is essentially a written job description for a unit of work.
- A healthy Stage 3 acceptance rate runs roughly 92 to 94 percent.
- Agents can be confidently wrong on trivial tasks, so reviewers cannot relax on easy work.
- Maturity is measured by how much you can responsibly hand off, not how good the tools are.
- Stages 3 and 4 require factory infrastructure before agents run on real work; most organizations sit at Stage 2 while believing they are at Stage 4.
