# Confidence-Correctness Gap

The confidence-correctness gap is the observation that AI agents fail differently from people: an agent's fluent, confident output is not a reliable signal that the work is correct. It matters because Stage 3 practitioners shift from producing artifacts to directing and reviewing agent output, and that review discipline depends on not trusting tone as a proxy for quality.

## Key Claims

- Agents fail differently than people: confidence decouples from correctness, so persuasive output can be wrong.
- Because the signal is unreliable, encoded standards must apply to everything the agent produces, raising the competence bar.
- A low-nineties acceptance rate on agent output is a health gauge for the encoded standards, not a target to maximize.
- Personal agents encode one person's judgment into repeatable form, but leave five practitioners with five definitions of "on track."
- Review effort must target correctness directly rather than reading confidence as evidence.
